# Лабораторна робота № 3 — Архітектурне та UX/UI-проєктування системи «Спокій»

Цей каталог містить результати лабораторної роботи № 3 з дисципліни «Технології створення програмних продуктів»: обґрунтування архітектурного стилю, ER-діаграму бази даних та UX/UI-проєктування (каркас і макет) для наскрізного проєкту — цифрової платформи-агрегатора ритуальних послуг «Спокій».

### Архітектурний стиль та архітектурна діаграма

Для системи «Спокій» обрано трирівневу (3-tier) клієнт-серверну архітектуру з чітким розділенням на рівень подання (React), рівень бізнес-логіки (Node.js/Express) та рівень доступу до даних (PostgreSQL). Вибір обґрунтовано простотою деплою, єдиною кодовою базою та відповідністю інкрементній моделі життєвого циклу проєкту. Діаграма (`architecture-diagram.png`) показує взаємодію рівнів між собою та із зовнішніми сервісами (платіжний шлюз, email/SMS).

### ER-діаграма бази даних

Діаграма (`er-diagram.png`) відображає дев'ять сутностей бази даних системи — Користувач, Партнер, Заявка, Позиція_замовлення, Труна, Ділянка, Церковна_служба, Оплата та Промокод — з первинними й зовнішніми ключами та зв'язками типу 1:N між ними.

### Каркас інтерфейсу (Wireframe)

Каркас (`wireframe.png`) демонструє структуру розташування елементів на чотирьох ключових екранах системи — «Увійти в систему», «Подати заявку», «Каталог трун» та «Особистий кабінет» — без кольорів і стилів, з метою перевірки логіки навігації.

### Макет інтерфейсу (Mockup)

Макет (`mockup.png`) показує остаточний вигляд тих самих чотирьох екранів з кольоровою палітрою, типографікою та іконками, стилізований у стримано-спокійних тонах відповідно до чутливої емоційної специфіки предметної області.
